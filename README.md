# قرآن — اپ اندروید آفلاین (MVP)

اپ خواندن قرآن با متن عثمانی **Tanzil**، کاملاً آفلاین، بدون ثبت‌نام و بدون هیچ اجازهٔ دسترسی.

- **Kotlin + Jetpack Compose + Material 3** (فقط APIهای پایدار، بدون annotation آزمایشی)
- **معماری MVVM** — Repository → DAO(Room) → ViewModel → Screen
- **Room** با دیتابیس پیش‌ساختهٔ قابل بازتولید، **Hilt** برای DI، **DataStore** برای تنظیمات
- minSdk **24**، target/compileSdk **36**، RTL کامل، رشته‌ها در `strings.xml` (فارسی + عربی)

## امکانات MVP

- فهرست ۱۱۴ سوره (نام فارسی/عربی، تعداد آیه، مکی/مدنی) + «ادامهٔ خواندن»
- صفحهٔ خواندن با فونت Amiri Quran، هدر بسم‌الله (مدیریت‌شده فقط در لایهٔ نمایش)، شمارهٔ آیهٔ تزئینی
- جستجوی بدون اعراب (نرمال‌سازی از پیش‌محاسبه‌شده در ستون جداگانه؛ متن اصلی هرگز تغییر نمی‌کند) + هایلایت نتیجه
- نشانه‌گذاری آیه‌ها + ذخیرهٔ آخرین جای خواندن (اسکرول → DataStore با debounce)
- اندازهٔ فونت (۱۸–۴۰sp) و حالت شب (سیستم/روشن/تیره)
- صفحهٔ «درباره و منابع» با ذکر منبع Tanzil و پیوند (الزام مجوز)
- صفحهٔ آزمایشی فونت (برای بازبینی رندر روی دستگاه)

خارج از محدودهٔ MVP: صوت، تفسیر، ترجمهٔ نمایش‌داده‌شده، حساب کاربری، بک‌اند، اعلان.
**لایهٔ ترجمه از حالا آماده است:** جدول `translations(translator, surah, ayah, text)` + `TranslationDao` — افزودن ترجمه فقط insert در این جدول + UI است، بدون دست‌زدن به جدول‌های متن.

## ساختار

```
quran-android/
├── data/tanzil/            فایل‌های خام Tanzil (متن + متادیتا + صفحات مجوز)

├── scripts/
│   ├── fetch_data.sh       دانلود مجدد داده از Tanzil
│   ├── validate_quran.py   اعتبارسنجی اجباری (۱۱۴/۶۲۳۶/پیوستگی/بسم‌الله/جزءها)
│   ├── build_db.py         ساخت assets/databases/quran.db + چک همگامی ثابت‌های کاتلین
│   └── gen_icons.py        تولید آیکون‌ها
├── gradle/libs.versions.toml  نسخه‌های پین‌شده (+ توضیح سازگاری)
├── SOURCES.md              منبع و مجوز هر داده/فونت + متن دقیق شرایط Tanzil
├── PRIVACY_POLICY.md       سیاست حریم خصوصی نمونه
└── BUILD_NOTES.md          راهنمای باز کردن/بیلد + خطاهای محتمل + وضعیت تست‌ها
```

## Build

پیش‌نیاز: **Android Studio** (جدیدترین نسخهٔ پایدار — جزئیات در BUILD_NOTES.md) و JDK 17+.

```bash
# ۱) باز کردن پوشه در Android Studio و صبر برای Sync
#    یا از ترمینال:
./gradlew assembleDebug          # بیلد debug
./gradlew test                   # تست‌های واحد (نرمال‌ساز/اعتبارسنج/جستجو)
./gradlew bundleRelease          # خروجی AAB (نیازمند امضا — BUILD_NOTES.md)
```

نکته: فایل `gradle-wrapper.jar` در مخزن نیست؛ Android Studio خودش wrapper را می‌سازد، یا یک‌بار دستی: `gradle wrapper --gradle-version 8.13` (جزئیات در BUILD_NOTES.md).

## پایپ‌لاین داده (تکرارپذیر)

```bash
bash scripts/fetch_data.sh          # ۱) دانلود از Tanzil
python3 scripts/validate_quran.py   # ۲) اعتبارسنجی — اگر FAIL شد ادامه ندهید
python3 scripts/build_db.py         # ۳) ساخت دیتابیس پیش‌ساخته + خودآزمایی
python3 scripts/gen_icons.py        #    (اختیاری) بازتولید آیکون‌ها
```

`build_db.py` در هر اجرا این‌ها را چک می‌کند: ۱۱۴ سوره، ۶۲۳۶ آیه، ۳۰ جزء، بدون متن خالی، integrity، برابری `text_simple` با نرمال‌سازی متن، و **برابری بایت‌به‌بایت ثابت‌های بسم‌الله در کاتلین با داده**.

## چرا این نسخه‌ها سازگارند؟

| قطعه | نسخه | دلیل |
|---|---|---|
| Gradle | 8.13 | حداقلِ لازم برای AGP 8.11 |
| AGP | 8.11.1 | پشتیبانی بومی compileSdk 36؛ JDK 17 |
| Kotlin | 2.1.21 | پایدار؛ کامپایلر Compose همراه خود Kotlin 2.x به‌صورت plugin می‌آید (نسخهٔ جدا لازم نیست) |
| KSP | 2.1.21-2.0.1 | KSP نسخه‌اش `<kotlin>-<ksp>` است و پیشوند باید دقیقاً نسخهٔ Kotlin باشد |
| Compose BOM | 2025.06.01 | آرتیفکت‌های پایدار (ui 1.8.x، material3 1.3.x)؛ در کد فقط API پایدار استفاده شده |
| Hilt | 2.56.2 | پشتیبانی KSP2/Kotlin 2.1 |
| Room | 2.7.1 | KSP-محور، سازگار با Kotlin 2.1 |
| Navigation | 2.9.0 | جفتِ رسمی با Lifecycle 2.9.x |

اگر هر نسخه‌ای روی ماشین شما resolve نشد، راه‌حل دقیق در BUILD_NOTES.md هست.

## تغییرات لازم قبل از انتشار

1. **applicationId** فعلاً `com.uthmani.quran` است — قبل از انتشار در Store به دامنهٔ خودتان تغییر دهید (بعد از اولین انتشار قابل تغییر نیست).
2. امضای release (keystore + متغیرهای QURAN_* — BUILD_NOTES.md).
3. بازبینی دستی صفحهٔ آزمایش فونت روی امولاتور/دستگاه (توسعه‌دهنده این را تست نکرده).
4. متن PRIVACY_POLICY.md را با نام/ایمیل ناشر پر کنید.

## وضعیت راستی‌آزمایی (صادقانه)

- ✅ اجراشده در همین محیط: دانلود داده، `validate_quran.py` (همهٔ چک‌ها PASS)، `build_db.py` (همهٔ چک‌ها PASS)، تولید آیکون‌ها، صحت فایل فونت (sfnt + sha256).
- ⛔ **تست‌نشده** (نیازمند Android SDK/دستگاه): کامپایل کاتلین، تست‌های واحد روی JVM واقعی، عملکرد Room در زمان اجرا، رندر فونت، مسیرهای UI، بیلد release/AAB.
